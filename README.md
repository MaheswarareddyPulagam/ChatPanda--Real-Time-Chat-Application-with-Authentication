# ChatPanda 🐼

A full-stack real-time chat application with authentication and WebSocket-based messaging.

## Tech Stack
- React
- Node.js
- Express
- MongoDB
- Socket.IO
- JWT Authentication

## Features
- User signup & login
- JWT-based authentication
- Real-time messaging
- Typing indicator
- Online users list
- Message persistence
- Auto-scroll chat
- Responsive UI
